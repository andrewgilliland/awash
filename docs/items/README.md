# Item Catalog

Items are grouped into three broad categories based on how the player uses them.

## Supplies

Consumable items used during exploration and combat.

- [Restoratives](supplies/restoratives.md)
- [Ammunition](supplies/ammunition.md)
- [Remedies](supplies/remedies.md)

## Equipment

Persistent items that change the player's combat capabilities or defenses.

- [Weapons](equipment/weapons.md)
- [Armor](equipment/armor.md)
- [Accessories](equipment/accessories.md)

## Relics

Magical items connected to the island's sealed knowledge.

- [Arcane Relics](relics/arcane-relics.md)
- [Traversal Relics](relics/traversal-relics.md)
- [Memory Relics](relics/memory-relics.md)
