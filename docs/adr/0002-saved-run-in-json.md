# The Saved Run is one versioned JSON file in user://

The Run is saved to `user://run.json`, one slot, as a JSON object of every part of `RunState` but `intro_pending`, with a `version` number (`RunState.SAVE_VERSION`). JSON matches the World's data (ADR 0001), is easy to read when a save goes wrong, and round-trips `RunState`'s plain values; Godot's binary `store_var` and Resources were passed over as opaque, and a Resource can carry scripts. A Saved Run of another version, missing a part, mistyping one, or saved in a Room the World no longer holds, is refused as a whole and the file is left in place, so there is no CONTINUE: there is no migration yet, and adding a part, or changing what one means, must bump the version, which leaves older saves behind unless a migration is written for them. Each write goes to `run.json.tmp` and is renamed over the old file, so a crash part-way never leaves a broken save. A test run (any run whose SceneTree has a script of its own) writes `user://test_run.json` instead, so tests never touch the player's own.
